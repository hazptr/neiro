Privacy

Last updated 20 October 2026. Applies to every Neiro version; 0.21.2.9 and earlier linked to Mihon's policy by mistake.

Neiro has no analytics, no crash reporting, no ads and no account. The app you download contains no analytics or crash-reporting code (no Firebase), and there is no Neiro server: nothing you do in the app is sent to the people who make it. GitHub, which hosts the downloads, shows download counts for each release.

What is stored on your device

  • In Neiro's own storage: your library, reading history, categories, settings, tracker logins, and caches of pages, covers and background music. Site cookies and storage from WebView are kept here too, until you clear them in Settings, Advanced.
  • In the folder you choose: downloaded chapters (with their background music, if that setting is on) and backups. Neiro makes an automatic backup there every 12 hours by default. If that folder syncs to a cloud service, your backups go there too.
  • Phone backups: Neiro opts out of Google cloud backup, but Android may still copy its data when you set up a new phone from an old one.

Extensions

Extensions are code written by third parties. They run inside Neiro with the same access to your library and settings that Neiro has, and they connect to the sites they read from to search, show details, load pages and fetch background music. Those sites see your IP address and the requests you make, under their own privacy policies. Nothing technically stops an extension from contacting other addresses, so only install extensions from stores you trust.

What Neiro connects to

  • Updates. Neiro asks GitHub (api.github.com) for the latest release at most once every six hours, whether it stays open or you reopen it, and whenever you tap Check for updates. Versions before 0.21.2.11 could also check again after a restart or a screen rotation. Downloading an update fetches the APK from GitHub.
  • Extension stores you add. Each time Neiro starts it refreshes the index of every store you've added, and it downloads extension files and icons from the addresses the store lists. No store is added by default, but restoring a backup brings back the stores it contains.
  • Images in text. Images inside manga descriptions and release notes load from wherever they're hosted.
  • WebView. Pages you open in WebView load in your device's system WebView. When a site shows a browser check, Neiro may also load it in a hidden WebView automatically. As in a browser, sites in WebView can ask for your device model and Android version.
  • Trackers. Only after you log in to one. Neiro then sends the titles you search for and your reading status, progress, score and dates, and keeps them in sync as you read. Logins use the apps Mihon registered with those services, so the services see the requests as coming from Mihon.
  • DNS over HTTPS. Only if you turn it on in Settings, Advanced. It covers Neiro's own requests; WebView still uses your normal DNS.
  • Connections. Some sites only work over unencrypted HTTP, so Neiro allows it, and Neiro trusts certificates you install yourself.

Crash logs

Crash logs are written to your device and only leave it if you share one. A crash log contains a random installation ID, your device model and Android version, your WebView version, your time zone, your extension list and recent app logs. With verbose logging turned on, those logs can include login tokens and cookies, so check a log before you share it.

Permissions

  • Internet, network and Wi-Fi state: to connect, and to respect the Wi-Fi only setting for downloads.
  • Notifications: for new chapters, library updates and errors, downloads, backups and restores, extension updates and incognito mode.
  • See installed apps: to find which extensions are installed. The list never leaves your device.
  • Install, update and uninstall apps: to manage extensions. Shizuku can be used for this if you set it up.
  • Biometrics: for the optional app lock.
  • Storage: legacy storage permissions are declared for older Android versions, but Neiro only uses the folder you pick.
  • Background work: foreground services, wake locks and starting at boot, so downloads, library updates and backups finish and stay scheduled. Neiro can ask to be exempt from battery optimisation for the same reason; that is up to you.
  • App language: to use the language you pick for Neiro.

These websites

This covers hazptr.github.io, /neiro/ and /neiro-extensions/. They are hosted on GitHub Pages, so GitHub handles every visit under the GitHub privacy statement. The pages call the GitHub API from your browser to show the latest release and the project list, and the extension store page loads the store index and extension icons from GitHub. The only thing stored in your browser is whether you turned the bubble sound on. There are no cookies and no analytics.
